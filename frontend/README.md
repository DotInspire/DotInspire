# Dot Inspire Design Studio — Frontend Application

Luxury interior design showcase and portfolio frontend built with React, Vite, TypeScript, and Tailwind CSS.

## 🚀 Setup & Run

1. Copy `.env.example` to `.env`:
   ```bash
   VITE_API_BASE_URL="http://localhost:5000/api"
   ```
2. Install dependencies & run dev server:
   ```bash
   npm install
   npm run dev
   ```
3. Build production bundle:
   ```bash
   npm run build
   ```
